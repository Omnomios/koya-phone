# Power-menu icons

Original vector power, restart and lock symbols. Their orange (#D96A1D),
warm cream (#F4E9D8), and rounded forms reference the Koya fish branding at
https://koya-ui.com/ (fish logo: https://koya-ui.com/koya_icon_64.png).
The button surfaces use the fish logo's deep green, independent of the wallpaper.

SVGs are the editable sources. Run `python3 scripts/render-power-icons.py` to
refresh the 160px PNG textures using the system librsvg/Cairo libraries.
